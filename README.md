# Licence Saathi | EasyDL
> A friction-free learner licence journey for India.

Built for **Hackcache26 (MARK-III Mparivahan)**.

## Overview
Licence Saathi simplifies the driving licence journey for citizens across India with a mobile-first, 360px viewport experience:
- **Eligibility Checker**: Calculate minimum age by vehicle class (MCWOG, MCWG, LMV) and view required state documents.
- **Mock Test Simulator**: Interactive RTO road safety and traffic sign practice tests.
- **Application Status Tracker**: Live tracking powered by Supabase.

## Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS + shadcn design tokens
- **Animations & Smooth Scroll**: Framer Motion & Lenis
- **Backend & Database**: Supabase (PostgreSQL with Row Level Security)
- **Deployment**: Vercel

## Local Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
